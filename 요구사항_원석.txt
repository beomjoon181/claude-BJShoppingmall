클로드야, 나는 'BJShoppingmall'이라는 쇼핑몰 웹페이지를 개발하고 싶어. 이 웹페이지에는 아래와 같은 것들이 필요해.
	- 일반 모드
		- 메인 화면: 제품(제품 사진을 카드 형태로)들 나열, 로그인 페이지로 가는 버튼
		- 상세 화면: 메인화면에 나열되어 있는 제품을 클릭하면 나오는 화면. 제품 사진, 가격, 할인 제품이면 할인가격도 표시, 제품 설명(사진들), 구매 버튼과 장바구니 버튼이 있고 버튼을 누르면 '로그인 하세요'하는 알림창과 함께 로그인 화면으로 이동
	- 로그인 화면
	- 회원가입 화면
	- 로그인 모드
		- 메인 화면: 일반 모드와 같으나 로그인 페이지로 가는 버튼이 마이페이지로 가는 버튼으
로 되어 있음. 장바구니 버튼도 새로 생김
		- 상세 화면: 일반 모드와 같으나 구매 버튼을 누르면 구매 페이지로 이동하고 장바구니 버튼을 누르면 상품이 장바구니에 담기면서 장바구니 페이지로 이동함.
		- 장바구니 페이지: 장바구니에 들어있는 상품들이 표시되고 구매하기 버튼과 취소하기 버튼이 있음. 취소하기 버튼을 누르면 장바구니에 있는 상품들이 전부 삭제되고 메인화면으로 돌아감. 구매하기 버튼을 누르면 구매 페이지로 넘어감.
		- 구매 페이지: 구매할 상품들이 표시되고 구매하기 버튼이 있음.
	- 관리자 모드
		- 메인 화면: 일반 모드와 같으나 로그인 페이지로 가는 버튼이 마이페이지로 가는 버튼으로 되어있고, 맨 첫 제품 카드에 제품 대신 '+' 사진이 올라와 있는 추가하기 카드가 있음. 나머지 제품들에는 수정버튼과 삭제버튼이 오른쪽 구석에 달려있고, 수정 버튼을 누르면 수정 페이지로 넘어가고, 삭제 버튼을 누르면 '삭제하시겠습니까?'하는 알람이 뜨고, '예'를 누르면 삭제가 됨.
		- 상세 화면: 일반 모드와 같으나 구매하기 버튼과 장바구니 버튼이 없음.
		- 수정 화면: 상세 화면과 같으나, 제품 사진을 추가할 수 있는 '+'사진이 올라와 있는 추가하기 버튼이 제품 사진 제일 첫 칸에 있고, 뒤에 나열되는 제품 사진들은 오른쪽 위 구석에 '-'버튼이 있고 누르면 '삭제하시겠습니까?' 알람이 나오고 '예'를 누르면 제품 사진이 삭제가 됨. 가격 오른쪽에 변경 버튼이 있고 누르면 아래에 입력 폼이 나타난다. 할인 여부를 체크할 수 있는 체크박스가 있고, 할인을 할 경우의 할인율이 있다. 할인율 옆에는 변경 버튼이 있고 누르면 입력 폼이 나타난다.
그 다음 제품 설명 사진들이 나올 때, 제품 설명 사진 맨 첫번째에 '+'사진이 올라와 있는 추가하기 버튼이 있고, 그 뒤로 나열되는 제품 설명 사진들은 오른쪽 위 구석에 '-'버튼이 있고 누르면 '삭제하시겠습니까?'알람이 나오고 '예'를 누르면 제품 설명 사진이 삭제가 됨.

이걸로 요구사항들을 분석해서 요구사항.md로 정리해줘

==========================================================

확인이 필요한 사항에 대해 - 요구사항을 변경해줘.
1. 제품 등록 정보에 제품명을 추가해줘.
2. 회원가입 때 관리자 여부를 선택하지 못하게 해줘. DB에서 직접 지정할 예정.
3. 마이페이지는 아직 만들지 않을 예정
4. 로그아웃 버튼은 상단 헤더에 배치
5. 메인화면의 추가하기 카드를 눌렀을 때 제품등록화면으로 보내줘.
6. 장바구니/구매 시 수량을 고를 수 있어.
7. 장바구니 개별 삭제는 만들지 않아. 일단 전체 삭제만 만들어줘.
8. 구매 완료 후 처리는 일단 만들지 않아.
9. 바로 구매시 장바구니와 상관없이 그 제품만 구매해.
10. 수정 저장 방식은 저장 버튼으로 한꺼번에 저장해.
11. 할인율 미입력시 할인 체크박스를 끄면 값은 유지하되 할인 가격은 표시하지 않아.
12. 할인 가격 계산은 소수점은 전부 반올림해.
13. 사진 개수는 최소 1장, 최대 10장
14. 재고 관리는 필요없어.
15. 관리자는 장바구니가 없어.
